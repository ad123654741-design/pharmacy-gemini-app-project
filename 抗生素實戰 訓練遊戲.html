2-1 β-lactamase Ambler 分類與新一代抑制劑對照

Class A (Serine)

酵素： TEM, SHV, CTX-M (ESBL), KPC

對策： ESBL首選 Carbapenem；KPC首選 Vaborbactam 或 Avibactam (Zavicefta)。

Class B (Metallo, MBL)

酵素： NDM, VIM, IMP (依賴鋅離子)

對策： 傳統抑制劑與Avibactam皆無效！唯一解：Aztreonam + Avibactam 或 Cefiderocol。

Class C (AmpC)

高風險三菌： E. cloacae, K. aerogenes, C. freundii

對策： 避免3代頭孢與Tazocin；首選 Cefepime (若MIC≤2) 或 Carbapenem。

Class D (OXA)

酵素： OXA-48 (腸桿菌)、OXA-23/24/58 (AB菌)

對策： OXA-48用 Avibactam；CRAB OXA首選 Sulbactam-durlobactam (Xacduro)。

口訣精華： K看V (KPC→Vaborbactam) · O看A (OXA-48→Avibactam) · N看ATM (NDM→Aztreonam) · CRAB看D (Durlobactam)。

2026 短療程實證與里程碑試驗 (Landmark Trials)

BALANCE Trial (NEJM 2025) 菌血症 7天不劣於 14天

針對非 S. aureus 菌血症 (n=3,608)，前提為臨床穩定、感染源控制良好，7天療程死亡率不劣於14天。

MERINO Trial (JAMA 2018) ESBL 菌血症 Tazocin 死亡率倍增！

即使藥敏報告 Tazocin 顯示 Susceptible，30天死亡率仍顯著高於 Meropenem (12.3% vs 3.7%)，因此嚴禁使用。

STOP-IT Trial (NEJM 2015) 腹腔內感染 source control 後 4天

充分外科引流或手術後，抗生素使用 4 天即足夠，延長使用無額外益處。

ATTACK Trial (Lancet ID 2023) CRAB 首選 Sulbactam-durlobactam

相較 Colistin，Sulbactam-durlobactam + Carbapenem 治療嚴重 AB 菌感染具更佳治癒率且腎毒性極低。

Part 7: PGY 最常犯的十個抗生素錯誤

  • 1. 治療無症狀菌尿 (ASB)： 長期導尿管尿液有菌但無全身症狀時不要打抗生素！(孕婦/泌尿處置除外)
  • 2. 用 Daptomycin 治肺炎： 會被肺泡表面張力素 (Surfactant) 破壞而失活。
  • 3. 用 Tigecycline 治菌血症或尿路感染： 老虎怕水，血中與尿中濃度極低！
  • 4. ESBL 菌血症用 Tazocin： MERINO 試驗證實死亡率大增，Carbapenem 才是首選。
  • 5. Tazocin / Mepem 再外加 Metronidazole： 厭氧菌覆蓋重複，浪費且增加副作用。
  • 6. 看到 Penicillin 過敏標籤直接跳後線： >90% 其實不過敏，頭孢交叉反應極低 (<1-2%)。
  • 7. MSSA 繼續打 Vancomycin： Vancomycin 殺 MSSA 效率遠遜於 Cefazolin/Oxacillin。
  • 8. Ertapenem 用於 ICU 經驗性用藥： Ertapenem 打不到綠膿與 AB 菌，台灣 ICU 不適用。
  • 9. 三天沒進步就一直升階： 先回頭找 Source control (引流、拔管) 而不是狂加藥！
  • 10. 開藥時沒有寫預計療程： 需落實 48-72 小時 Antibiotic Time-out。
