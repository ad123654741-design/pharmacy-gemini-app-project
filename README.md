# 藥品近效期智慧監控與作業系統 (Pharmacy Expiry Tracker)

由醫院藥局 `藥品效期整理程式.xlsm` (Excel VBA) 全面升級轉型的純靜態網頁版應用程式，可直接部署於 **GitHub Pages**，免安裝、開啟即自動整理，並選配 **Google Sheets** 雲端多人同步。

## 核心特色

1. **原生直讀醫院 HIS 匯出檔（免再開 Excel 複製貼上）**
   - 直接上傳庫存系統匯出的 `.xls`（HTML 表格格式）、`.xlsx`、`.csv` 與門診藥品基本檔清單 (`PHRQ060`)。
   - 徹底解決 Excel 複製貼上導致藥碼被誤判為日期（例如 `JUL01` → `46204`）的問題。
   - 亦支援直接上傳舊版 `藥品效期整理程式.xlsm`，一鍵帶入兩張工作表！
2. **開啟即自動整理、精簡主介面**
   - 移除繁瑣的「開始執行整理」與「重置預設參數」按鈕，資料與參數任何變動皆**即時自動重算**，且每日打開網頁自動以當天日期動態倒數剩餘天數。
   - 主頁面只保留最常用的「排除基準日期」、搜尋欄與互動式 KPI 卡片；其餘固定參數收納於「進階設定」。
   - 結果表格精簡移除「調劑特性」與「稽核備註」，聚焦核心欄位與現場作業。
3. **特定藥碼排除（疫苗 / 公費 / 雜訊黑名單）**
   - 支援批次輸入排除藥碼、主表格單鍵快速排除（含復原提示）、自動排除 `-CDC` 批號開關，以及**一鍵智慧掃描疑似疫苗/公費品項**。
4. **兩段式近效期作業追蹤（🏷️ 貼標 → 📦 下架）與防漏升級警示**
   - 以 `藥碼 + 批號 + 效期` 精準追蹤同藥不同批號的進度，記錄貼標日、下架日、經手藥師與處置備註。
   - **防漏升級機制**：先前已貼標的藥品，當倒數進入緊急下架門檻（預設 ≤30 天）卻尚未下架時，系統自動亮起 **🚨 已貼標，屆期待下架！** 警示並浮至待辦清單。
   - 內建「同藥碼其他批號庫存參考」、「批次標記」與「列印藥架巡檢單 / 匯出評鑑稽核 Excel」。
5. **三層資料分離，3~6 個月重新上傳安心覆蓋**
   - 重新上傳新 Excel 時**無須先按清除**，自動安全覆蓋原始清單並顯示差異報告（新增批號 / 已耗盡批號 / 繼承既有紀錄數）。
   - 既有貼標/下架紀錄與排除設定永久保留，已耗盡消失的批號自動轉入「歷史封存」分頁備查。

## 一、部署到 GitHub Pages（3 分鐘完成）

1. 在 GitHub 建立一個新的 Repository（例如 `pharmacy-expiry-tracker`）。
2. 將本資料夾內的 `index.html`、`app.js`、`README.md`、`google-apps-script/Code.gs` 上傳（push）至 `main` 分支。
3. 到 Repository 的 **Settings → Pages**：
   - **Source** 選擇 `Deploy from a branch`
   - **Branch** 選擇 `main` / `/ (root)`，點擊 **Save**。
4. 等待約 1 分鐘，即可透過 `https://<你的帳號>.github.io/pharmacy-expiry-tracker/` 開啟使用！

> **資安提醒**：本專案程式碼不含任何醫院實際庫存資料。使用者上傳的 Excel 僅存於本機瀏覽器 `IndexedDB` 或藥局私人的 Google 試算表，不會公開在 GitHub 上。

## 二、選配：串接 Google Sheets 雲端多人同步（5 分鐘完成）

若希望藥局多台電腦共享「貼標/下架進度」、「排除藥碼設定」與「最新效期清單」：

1. 用藥局共用 Google 帳號建立一份新的 Google 試算表（例如命名為 `藥局近效期管理資料庫`）。
2. 點選試算表上方選單：**擴充功能 → Apps Script**。
3. 刪除編輯器中原本的程式碼，將 [`google-apps-script/Code.gs`](./google-apps-script/Code.gs) 全部複製貼上。
4. （強烈建議）修改第 17 行 `const ACCESS_TOKEN = '您的藥局密碼';` 作為簡易安全防護，按 Ctrl+S 存檔。
5. 點右上角 **部署 → 新增部署作業**：
   - 選取類型：**網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 點擊「部署」並授權存取試算表。
6. 複製產生的 **網頁應用程式網址**（結尾為 `/exec`）。
7. 開啟網頁版 → 右上角 **進階設定 → Google Sheets 雲端同步** → 貼上網址與密碼 → 點「測試連線」→ 成功後點「立即上傳同步至雲端」即完成！

> 之後 Google 試算表中的 `ActionLogs` 分頁會自動整理成乾淨表格，評鑑查核時可直接從試算表列印或匯出。
